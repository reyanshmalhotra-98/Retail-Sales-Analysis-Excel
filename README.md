# Retail Sales Analysis & Performance Dashboard

## Project Overview
This project presents an interactive Retail Sales Dashboard built using Microsoft Excel to analyze revenue distribution across different product categories and monthly sales trends.

## Key Insights
- **Total Revenue Generated:** 2,44,435
- **Top Product Category:** Electronics led sales revenue, followed by Clothing and Beauty.
- **Sales Trends:** Visualized monthly revenue fluctuations using pie distributions and dynamic product category slicers.

## Tools & Features
- **Pivot Tables & Pivot Charts:** Dynamic sales aggregation by category and month.
- **Slicers:** Category filtering (Beauty, Clothing, Electronics) for real-time dashboard updates.
